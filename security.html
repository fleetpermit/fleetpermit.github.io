Security model

Every missing input, error or unreachable component results in less authority, never more. Here is how that holds, and where it stops.

Trust boundaries

The hub decides; it does not sit in the request path. Kubernetes RBAC on the hub decides who may write a FleetAccessPolicy (the ceiling) and who may create a ToolAccessLease (activation), so on-call engineers can activate access without being able to change the ceiling. FleetPermit never issues, stores or sees credentials. The gateway authenticates the caller from its mTLS peer certificate.

Principles

  1. Ceiling and activation are separate objects

    A FleetAccessPolicy defines the maximum. A ToolAccessLease activates part of it for a bounded time.

  2. Enforce where the call happens

    Identity, tool and time are all checked by the gateway in front of the tool server.

  3. Fail closed

    No placement means nothing is delivered. A render error withdraws that cluster's grants. A lease that violates its policy is Denied, and Denied is terminal. A backend without any grant is closed by the default-deny anchor. failMode accepts only Closed.

  4. Subset only

    A lease can narrow tools, duration and clusters, never widen them, and its spec cannot be edited after creation.

  5. Traceable

    Every delivered object names its policy, generation, lease, cluster, expiry and SHA-256 content digest, so a rule found on a cluster leads back to the request that created it.

Honest limits

  • Experimental upstream APIsXAccessPolicy (v1alpha1) and XBackend (v0alpha0) in kube-agentic-networking are experimental. Its reference implementation is not described upstream as production-ready.
  • No argument-level matchingkube-agentic-networking v0.2.0 matches the tool name only. A call such as scale_workload with replicas=1000 cannot be refused by argument.
  • About 9 concurrent grantsUpstream allows at most 5 XAccessPolicies per target and 10 rules per policy, so about 9 concurrent lease grants fit per policy per cluster. Excess leases are reported, never silently dropped.
  • Session methods are not time-boundedMCP session methods (initialize, tools/list) are allowed by a separate rule that the controller removes. They cannot call tools.
  • Managed cluster clocksExpiry uses each managed cluster's clock. A clock that runs behind honours a grant for longer, by the amount of skew.
  • Early revocation needs the hubDeleting a lease before it expires reaches only clusters the hub can contact. Keep lease durations short.
  • Local labAll measurements come from local kind clusters on one development host, not a production benchmark.

FleetPermit does not make tool calls safe, does not guarantee the absence of vulnerabilities, and does not replace RBAC, network policy or authorization inside the tool server. It narrows who can call which tool, where, and for how long, and it reports what it enforces.

Reporting a vulnerability

Please do not open a public issue. Use GitHub private vulnerability reporting on the repository: report a vulnerability. Only maintainers can see the report. See the security policy summary.
